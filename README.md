# Outreach Command Suite

A browser-based client workflow suite: Outreach Command CRM, ProposalCraft, Client Contract Builder, and Invoice Generator.

## Use

Open `index.html` locally, or enable GitHub Pages from the repository's `main` branch and `/ (root)` folder. In Outreach Command, open **Client Workspace**, choose a prospect, then create a proposal, contract, or invoice with their details pre-filled.

## Data

The tools run entirely in the browser and use local storage. No credentials are included in this repository.
